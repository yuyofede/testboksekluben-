# Grimstad Bokseklubb – website

A bilingual (Norwegian bokmål / English) static website for Grimstad Bokseklubb, built with hand-written HTML, CSS and JavaScript. No framework, package manager, build pipeline or backend is required.

- Norwegian pages live at the project root.
- English pages live in `en/`.
- All HTML is generated from `tools/build.py`; do not edit the generated `.html` files by hand.
- The contact form opens the visitor's e-mail client (`mailto:`). There is no server-side form handling.

## Preview locally

From the project root:

```sh
python3 tools/build.py
python3 -m http.server 8000
```

Then open <http://localhost:8000/>.

The site is plain static output, so any static host can serve the repository root. There is no `vercel.json`; a Vercel deployment should use the repository root as the output directory and no build command.

## Project structure

```
index.html, om-oss.html, ...   Generated Norwegian pages
en/                            Generated English pages
css/style.css                  All site styles and self-hosted @font-face rules
js/main.js                     Navigation, reveal, lightbox and mailto form
assets/img/                    Optimised WebP photos, logo and OG image
assets/fonts/                  Self-hosted WOFF2 fonts and OFL licences
assets/src/                    Original JPEGs downloaded from the club
tools/build.py                 Page generator and all NO/EN copy
sitemap.xml, robots.txt        Generated by tools/build.py
```

Page URLs are defined in `NO_FILES` / `EN_FILES`; page copy is in the page functions and `PAGES` list in `tools/build.py`. The build also writes `sitemap.xml` and `robots.txt`, so change the page list there rather than editing those files.

The site canonical base is `https://grimstadbk.com` (`SITE` in `tools/build.py`). Changing it updates canonical links, hreflang pairs, Open Graph URLs and the sitemap on the next build.

## Photos

All photos come from the club's own Instagram/Facebook posts. Originals are kept in `assets/src/`; responsive WebP versions are in `assets/img/` at 640, 1024 and (where the source allows) 1600 px. The logo is the badge supplied by the club.

Barlow Condensed and Inter are self-hosted in `assets/fonts/` to avoid third-party font requests. Both are licensed under the SIL Open Font License; the licence texts are included in the same directory.

## Before publishing – confirm with the club

1. **Training times.** The schedule is the club's last published timetable (2020):
   - Monday 19:00–20:30, advanced
   - Tuesday 18:00–19:30, all levels
   - Wednesday 18:00–19:00, bag work
   - Thursday 17:30–18:30, “Boks stødig”
   - Thursday 19:00–20:30, all levels

   Confirm the current times, then edit `SCHEDULE` in `tools/build.py` and rebuild. The page already tells visitors to check Facebook/Instagram for changes.
2. **Domain.** `grimstadbk.com` is assumed because it is the club's existing domain. Confirm DNS and the final production URL, or change `SITE` and rebuild.
3. **Photo consent**, especially for the young boxers, and permission to name individual members.
4. **Contact person and role.** Henning Lillejord is listed as chair and head coach based on the club's public contact information.
5. **Historical claims** used on the About page: best club at the 2012 Norwegian championships, Jamshid Nazari's fifth professional win in 2019, and the 2026 milestones/news captions.
6. **Fees.** Membership fees are deliberately not listed because no current price list was available.

## Notes

- The contact form needs a configured e-mail client; it does not send mail by itself.
- Google Maps is loaded only on the contact page and is disclosed in the privacy page. No cookies, analytics or advertising scripts are used.
- The site uses no external font, analytics or CDN requests beyond the Google Maps iframe.
